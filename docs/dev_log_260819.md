# Dev Log 2026-08-19

## 동문 수첩 열람 요청

- 비공개·다른 기수 `cohort` 회원은 수첩에서 이름·기수만 보이고, 연락처·소속은 잠근다.
- 조회자는 `정보 보기 요청하기`로 당사자에게 알리고, 당사자가 내 정보에서 허용하면 그 조회자에게만 상세가 열린다.
- 푸시 구독이 있으면 대상에게 알림을 보낸다. 동문 간 쪽지함은 만들지 않았다.

## 동문 수첩 공개 동의

- 신규 회원은 동의 전까지 `private`로 잠그고, 비밀번호 만들기와 분리된 `/directory-consent`에서 공개 범위와 제17조 고지를 받는다.
- 거부해도 계정은 유지되고 수첩 상세만 잠긴다. `private` 선택은 공개 동의를 남기지 않아, 나중에 공개하려면 동의를 다시 받는다. 기존 `all` 회원은 일괄 재동의를 강제하지 않는다.
- `private`는 불특정 동문에게 비공개다. 개별 보기 요청을 허용한 사람에게만 상세가 열리고, 허용 취소로 그 사람만 다시 잠근다. 관리자도 회원 동의 없이는 `all`/`cohort`로 열 수 없다.
- Live E2E: 가입→승인→활성화→`/directory-consent`→동의 저장 후 다른 회원이 수첩에서 이메일을 본다. Mock regression 12건 통과.
