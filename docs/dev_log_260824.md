# 개발 로그 2026-08-24

- 이메일이 없는 기존 회원도 답변받을 이메일을 포함해 사무국 문의를 접수할 수 있도록, 지원문의 서비스의 nullable 이메일 계약을 복구하고 회귀 테스트를 추가했다.
- 문의 화면의 모호한 `연락처` 입력을 `답변받을 이메일`로 바꾸고 브라우저 이메일 형식 검증과 자동완성을 적용했다.
- 운영에서 확인된 문의 등록 422가 제목·내용 최소 길이 검증 실패임을 확인하고, 화면에 필수·최소 길이 제약과 안내를 연결했다.
- 로그인 전 공개 문의 화면과 API 권한을 일치시켜 익명 문의를 허용하고, 익명 중복 억제 키는 원문 IP를 남기지 않는 해시로 분리했다. 답변 이메일은 화면과 API 계약 모두에서 필수 이메일 형식으로 받는다.
- 문의 폼의 필수·길이·이메일 오류를 필드별 한국어 문구와 포커스로 안내하고, 422·429·저장 장애·연결 실패의 후속 행동을 구분했다.
